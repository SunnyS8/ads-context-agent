# Контекст проекта: Агент автоматизации контекстной рекламы

Проект автоматизирует управление, анализ и оптимизацию контекстной рекламы на площадках:
- **Яндекс.Директ** (через eLama API как основной прослой)
- **VK Ads (TARGETING)**

## Архитектура

```
eLama API (основной прослой для Яндекс.Директ)
    ↓
PlatformAdapter (абстрактный интерфейс)
    ↓
Бэкенд (FastAPI) → БД (PostgreSQL) → Redis
    ↓
AI-модули (анализ, генерация креативов)
    ↓
Фронтенд (Next.js) + Telegram-бот (aiogram)
```

## Правила безопасности

- Никогда не выполнять изменения в рекламных кампаниях без явного подтверждения пользователя.
- Не хранить API-ключи в Git. Использовать только переменные окружения из `.env`.
- Все изменения ставок/бюджетов записывать в `audit_log`.
- Для тестов использовать mock API. Реальные API-вызовы только в продакшне.
- При недостатке статистики выдавать рекомендацию, но не менять ставки.
- Не изменять дневной бюджет автоматически.
- Перед применением изменений показывать пользователю: кампанию, старое значение, новое значение и причину.
- Режим `DRY_RUN=true` по умолчанию — изменения не применяются, только логируются.

## Технологии

### Бэкенд
- Python 3.12
- FastAPI + Uvicorn
- SQLAlchemy 2.0 (async)
- Alembic (миграции)
- Pydantic v2
- httpx (HTTP-клиент)
- APScheduler (планировщик)
- aiogram 3.x (Telegram-бот)
- OpenAI API (генерация креативов)
- pytest + httpx (тесты)

### Фронтенд
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Recharts (графики)

### Инфраструктура
- PostgreSQL 15
- Redis 7
- Docker Compose

## Стиль кодирования

- Небольшие функции (до 50 строк).
- Строгая типизация Python и TypeScript.
- Обработка ошибок API с логированием.
- Тесты для всей бизнес-логики.
- Docstring для каждого публичного метода.
- Все API-клиенты реализуют общий интерфейс `PlatformAdapter`.

## Рекламные платформы

### eLama (основной прослой)
- Управление кампаниями Яндекс.Директ
- Aggregated Reports (статистика)
- Управление аккаунтом и оплата
- Авторизация: API-токен

### VK Ads (TARGETING)
- Управление рекламными кампаниями VK
- Сбор статистики
- Работа с аудиториями (lookalike, ретаргетинг)
- Авторизация: access_token
