# Анализ кампаний

Запускает анализ статистики и формирование рекомендаций.

## Использование

```
/analyze [период]
```

## Что делает

1. Загружает статистику за последние 7 дней через `StatsService`.
2. Рассчитывает KPI (CTR, CPC, CPA, ДРР) для каждой кампании.
3. Ищет аномалии через `AnomalyService`.
4. Формирует рекомендации через `RecommendationService`.

## Вывод

Список кампаний с KPI и найденными отклонениями. Формат:

```
Кампания: <название>
Показы: X | Клики: Y | CTR: Z%
Расход: N ₽ | Конверсии: M
CPA: C ₽ (цель: T ₽)
Аномалии: <список>
```

## Ограничения

- Только анализ, без изменения ставок.
- При недостатке данных — вывод «мало данных».
