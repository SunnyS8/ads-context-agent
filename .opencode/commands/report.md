# Отчет по кампаниям

Формирует отчет о состоянии рекламных кампаний.

## Использование

```
/report [период]
```

## Что делает

1. Собирает статистику всех кампаний за последние 7 дней.
2. Считает агрегированные KPI: CTR, CPC, CPA, CPL, ДРР.
3. Формирует сводку для Telegram и веб-панели.

## Вывод

```
Отчет за 7 дней:
Показы: ... | Клики: ...
Расход: ... ₽ | Конверсии: ...
CTR: ...% | CPC: ... ₽ | CPA: ... ₽ | ДРР: ...%
```

## Функции

- Экспорт в Excel/PDF (в разработке).
