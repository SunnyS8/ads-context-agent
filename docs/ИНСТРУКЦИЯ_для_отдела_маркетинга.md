# Инструкция: как работать с «Агент контекстной рекламы»

> Для отдела маркетинга. Без технических знаний.

---

## 1. Что это за инструмент и зачем он нужен

«Агент контекстной рекламы» — это программа, которая **собирает статистику по всем рекламным кампаниям в одном месте** и помогает маркетингу:

- видеть, сколько денег ушло и что получено (показы, клики, конверсии, расход);
- понимать ключевые показатели — CTR, CPC, CPA/CPL, ДРР, ROAS;
- замечать проблемы (аномалии): кампания не даёт конверсий, цена лида выросла, бюджет почти исчерпан и т.п.;
- получать **рекомендации**, что делать с кампанией (снизить ставку, на паузу, поднять ставку);
- получать сводные отчёты автоматически — по расписанию и по запросу.

Площадки: **Яндекс.Директ** (через eLama API) и **VK Ads (TARGETING)**.

## 2. Текущее состояние (что работает прямо сейчас)

| Что | Статус |
|---|---|
| API-сервер, база данных, Redis | Работает локально |
| Демо‑данные | Есть: 3 тестовые кампании, статистика за 7 дней |
| Рекомендации/аномалии | Работают на демо‑данных |
| Расписание (08:00 статистика, 08:35 рекомендации) | Включено, работает пока сервер запущен |
| Реальные площадки (eLama, VK) | **Не подключены** — нет API‑токенов (планируется в следующих этапах) |
| Telegram‑бот | Написан, но не запущен — нужен токен бота |
| Веб‑панель (Next.js) | В разработке, пока не используется |

**Важно про тестовый режим:** пока не подключены реальные API, все данные — **учебные/демо**. Система работает в режиме `DRY_RUN`: она **ничего не меняет на реальных площадках** (не тратит деньги, не меняет ставки). Это безопасно по определению.

## 3. Как запустить (пошагово)

> Нужен один раз. Программа запускается на служебном компьютере и работает,
> пока открыто окно запуска.

1. Откройте папку проекта: `Агент контекстной рекламы`.
2. **Двойной клик по файлу `start_local.bat`** (запуск).
   Программа сама сделает 4 шага и покажет надписи:
   - запуск базы данных и Redis;
   - обновление структуры базы;
   - заполнение демо‑данными;
   - запуск сервера.
3. Когда появится строка **`Uvicorn running on http://0.0.0.0:8000`** — всё работает.
   Окно закрывать **нельзя** (пока открыто — сервер работает).
4. Откройте браузер и проверьте: **http://localhost:8000/docs** — откроется
   «документация» (см. раздел 5).

### Как остановить
- Закройте окно запуска (`start_local.bat`).
- Двойной клик по **`stop_local.bat`** — это аккуратно остановит базу (необязательно,
  но желательно перед выключением компьютера).

### Если что-то пошло не так
- Синее окно закрыл — оно пишет ошибку и не закрывается (ждёт нажатия Enter). Сфотографируйте текст ошибки и покажите разработчику.
- Подсказки по частым проблемам — в разделе 8.

## 4. Ключевые показатели (короткий словарик)

| Показатель | Что значит | Хорошо, когда… |
|---|---|---|
| **Показы** | Сколько раз объявление показали | больше |
| **Клики** | Сколько раз по нему кликнули | больше |
| **Расход** | Сколько денег потрачено (₽) | в рамках бюджета |
| **Конверсии** | Сколько целевых действий (заявки/покупки) | больше |
| **CTR, %** | Доля кликов от показов — насколько объявление цепляет | выше |
| **CPC, ₽** | Цена за один клик | ниже |
| **CPL/CPA, ₽** | Цена за одну заявку (лид/конверсия) | ниже целевой |
| **ДРР, %** | Доля рекламных расходов от выручки | обычно до 20–30% |
| **ROAS** | Сколько ₽ выручки на 1 ₽ рекламы | выше 1 |

**Целевые значения по умолчанию в системе:**
- целевой CPL — 1 500 ₽;
- минимум конверсий для решения — 5 за период;
- окно анализа — последние 7 дней;
- ставку можно менять максимум на 15% за раз, верхний предел 250 ₽;
- бюджет автоматически не меняется никогда.

## 5. Как пользоваться через браузер (документация API)

Откройте **http://localhost:8000/docs** — это интерактивная «панель».
Выглядят как список функций программы. Любую функцию можно нажать и посмотреть результат.

Основные функции:

| Раздел | Кнопка (метод) | Что делает | Когда пользоваться |
|---|---|---|---|
| **campaigns** | `GET /api/v1/campaigns` | Показать все кампании | Сводка по кампаниям |
| | `POST /api/v1/campaigns` | Добавить кампанию вручную | Когда завели кампанию на площадке, а в системе её нет |
| | `PATCH /api/v1/campaigns/{id}` | Изменить статус/бюджет кампании | Поставить «на паузу» и т.п. |
| **statistics** | `GET /api/v1/statistics` | Показать статистику (можно фильтровать по кампании и датам) | Ежедневный просмотр цифр |
| | `POST /api/v1/statistics/sync` | Загрузить свежую статистику с площадок | Запрашивать статистику вручную |
| **recommendations** | `GET /api/v1/recommendations` | Показать рекомендации и аномалии | Что делать с проблемными кампаниями |
| | `POST /api/v1/recommendations/generate` | Пересчитать рекомендации | После загрузки статистики |
| **creatives** | `POST /api/v1/creatives/generate` | Сгенерировать текст объявления через ИИ | Подготовка текстов объявлений |

### Как нажать кнопку в `/docs`
1. Нажмите на функцию — она раскроется.
2. Слева вверху блока кнопка **«Try it out»**.
3. При необходимости заполните поля и нажмите **«Execute»**.
4. Ниже появится ответ (код 200 — всё хорошо, данные; 4xx/5xx — ошибка).

Подсказки:
- `GET`-функции безопасны — можно нажимать сколько угодно.
- `POST /statistics/sync` безопасен в тестовом режиме и **защищён от дублей** — можно нажимать повторно.
- После `sync` и `generate` данные сразу видны через `GET /statistics` и `GET /recommendations`.

## 6. Автоматические задачи по расписанию

Пока сервер запущен, программа сама (по московскому времени):

| Время | Действие |
|---|---|
| **08:00** | Загрузка статистики за 7 дней |
| **08:35** | Расчёт KPI, поиск аномалий, формирование рекомендаций |

То есть утром по приходу на работу цифры уже обновлены. Достаточно открыть
`GET /statistics` и `GET /recommendations` (или спросить бота — см. раздел 7).

## 7. Telegram‑бот (когда подключим)

Бот позволяет получать сводки прямо в Telegram, без браузера.
Сейчас **не активен** — нужно добавить токен в `.env` (`TELEGRAM_BOT_TOKEN`)
и запустить `bot/bot.py`. Когда заработает, у него будут команды:

- `/start` — приветствие;
- `/status` — сводка по всем кампаниям (активна/на паузе, бюджет);
- `/report` — отчёт за последние 7 дней (показы, клики, расход, конверсии, CTR, CPC, CPA);
- `/alerts` — последние рекомендации и аномалии.

## 8. Частые проблемы и их решение

| Проблема | Что делать |
|---|---|
| `localhost:8000` не открывается | Убедитесь, что окно `start_local.bat` открыто. Подождите 10–15 сек. Запустите снова. |
| Ошибка «port is already allocated» | На компьютере уже занят порт. Закройте лишние программы/окна с сервером и попробуйте ещё раз. |
| В статистике пусто | Нажмите `POST /api/v1/statistics/sync`, затем `GET /api/v1/statistics`. Если это демо — проверьте, что в базе есть кампании (`GET /campaigns`), иначе запустите `start_local.bat` ещё раз (он сам добавит демо‑данные). |
| Рекомендаций нет | Нажмите `POST /api/v1/recommendations/generate`. Если данных мало (< 5 конверсий), система намеренно не даёт активных рекомендаций — это нормально. |
| Окно со всплывающей ошибкой | Нажмите Enter, сфотографируйте текст, покажите разработчику. |
| Данные «не настоящие» | Сейчас идёт демо‑режим с учебными данными. Реальные кампании появятся после подключения eLama/VK-токенов (следующие этапы). |

## 9. Безопасность (обязательно к прочтению)

- В тестовом режиме система **не тратит деньги и не меняет ставки/бюджеты на площадках**.
- В любом режиме изменение ставок — **только после подтверждения пользователем** (не автоматически).
- Бюджет автоматически не меняется никогда.
- Секреты и токены хранятся только в файле `.env`, он не попадает в общий репозиторий.
- Все действия записываются в журнал (`audit_log`) — всегда видно, кто и что делал.
